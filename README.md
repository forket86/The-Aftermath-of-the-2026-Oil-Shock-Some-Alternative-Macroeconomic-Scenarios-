# The Aftermath of the 2026 Oil Shock: Some Alternative Macroeconomic Scenarios

**Jonas D. M. Fisher, Will Pennington, and Alessandro Villa**  
*Chicago Fed Letter*, No. 523, July 2026. Federal Reserve Bank of Chicago.  
DOI: [10.21033/cfl-2026-523](https://doi.org/10.21033/cfl-2026-523) · [Article](https://www.chicagofed.org/publications/chicago-fed-letter/2026/523)

This replication package contains the MATLAB scripts and inputs for Figures 1–4 of the article. Open MATLAB with this directory as the **Current Folder**; the scripts use paths relative to the package root. Filenames are case-sensitive on some systems: `fig1.m` is lowercase, while `Fig2.m`, `Fig3.m`, and `Fig4.m` begin with uppercase `F`.

## Requirements

- MATLAB. `Fig2.m`–`Fig4.m` additionally require [Dynare 7.0](https://www.dynare.org/).
- `fig1.m` requires access to the Haver Analytics `cbd.data` interface and a personal [FRED API key](https://fred.stlouisfed.org/docs/api/api_key.html), plus an internet connection. The package does **not** include Haver or a FRED key.
- The raw and derived data files listed below are supplied. The three model figures can be run using the supplied derived CSV files without first rerunning `commodity_prices.m` or `fig1.m`.

The scripts contain historical installation paths. In `Fig2.m`, `Fig3.m`, and `Fig4.m`, set `AleDirectory=1` on an Apple Silicon Mac using Dynare at `/Applications/Dynare/7.0-arm64/matlab`, or leave it at `0` for Dynare at `C:\dynare\7.0\matlab` on Windows. If your installation differs, edit the relevant `addpath` in **each** model script. In `fig1.m`, the Haver `addpath` points to a legacy Windows drive and must be changed to the location of your accessible `cbd` installation. `commodity_prices.m` contains the same legacy `addpath`, but makes no Haver calls.

## Run the figures

1. To rebuild the oil futures calibration, run `commodity_prices.m`. It reads `data_raw/commodityprices.csv` and `data_raw/commodities_info.xlsx`, writes `data_created/wtifutures_exp_March.csv`, and saves the auxiliary plot `figures_png/wti_expectations.png`. This step is optional when using the included derived CSV.
2. To rebuild Figure 1 and the historical oil-price path used in Figure 4, insert **your own** FRED key between the quotes in the `api_key = '';` line of `fig1.m`, configure Haver access, and run `fig1.m`. It reads `data_raw/petroleum_consumption_ann.xls`, requests Haver and FRED series, writes `data_created/wtichanges_seventies.csv`, and saves `figures_png/fig1.png`. This step is optional for Figures 2–4 when using the included historical CSV. Remove your key before sharing any edited copy of the script.
3. Set the Dynare path in each model script as described above. Run `Fig2.m`, `Fig3.m`, and `Fig4.m` to generate `figures_png/fig2.png`, `figures_png/fig3.png`, and `figures_png/fig4.png`, respectively. The included `oil_nonlinear_kstickyEPF_export3_sf.mod` is the Dynare model. Leave `casename = "Baseline"` and `printfigs = 1` for the article figures.

The scripts save images under `figures_png/`. That directory is included empty so the data-preparation scripts can write to it immediately. Dynare also creates temporary model code, results, and a log while the model scripts run; those generated files are intentionally absent from this clean copy.

## Included inputs

| Path | Purpose |
| --- | --- |
| `data_raw/commodityprices.csv` | Commodity and oil-futures price observations used by `commodity_prices.m` |
| `data_raw/commodities_info.xlsx` | Series information used by `commodity_prices.m` |
| `data_raw/petroleum_consumption_ann.xls` | Annual petroleum-consumption data used by `fig1.m` |
| `data_created/wtifutures_exp_March.csv` | Included oil-futures calibration for Figures 2–4; regenerated by `commodity_prices.m` |
| `data_created/wtichanges_seventies.csv` | Included historical oil-price path for Figure 4; regenerated by `fig1.m` |

The raw commodity-price extract was supplied with the original package and contains a June 2026 snapshot. `fig1.m` requests Haver observations through the current date, and external Haver/FRED data can be revised; a later full rerun may therefore differ from the originally supplied derived CSVs or published image. For exact comparison with the supplied model inputs, retain copies of the included derived CSVs before regenerating them.

If MATLAB displays figures with dark plot backgrounds, set **MATLAB → Settings → MATLAB → Appearance → Figure Theme → Light** before running the scripts. This affects display only; it does not change the model calculations.
